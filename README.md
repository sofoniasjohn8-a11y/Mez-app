# ቤተ-ዕንዚራ — የበገና መዝሙሮች

A mobile app for browsing, searching, and listening to 335 Ethiopian Begena mezmurs (hymns).

## Features
- 🔍 Search by title, author or lyrics (Amharic)
- 🏷️ Filter by category: ሰላምታ, ስለ ቸርነትህ, ዋኔን, አምባሰል
- ⭐ Favorites list
- 🕘 Recently viewed history
- 🎵 Audio download & offline playback
- 🌙 Dark / Light mode
- Nyala font throughout

## Setup

```bash
npm install
npx expo start
```

## Stack
- React Native + Expo SDK 58
- TypeScript
- Fuse.js (search)
- expo-audio (playback)
- expo-file-system (offline storage)
